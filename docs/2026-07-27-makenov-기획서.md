# MAKENOV (메이크노브) 기획서

작성일: 2026-07-27 · 상태: 기획 확정 (구현 전)

## 1. 컨셉

**인디고고처럼 생겼지만, 펀딩이 아니라 바이어 문의를 모으는 B2B 쇼케이스 플랫폼.**

- 대상 제품: 한국의 혁신 제품 (1차 배치: 대구 기업 → 이후 전국 → 글로벌)
- 대상 방문자: 베트남 바이어 (1차 시장 → 이후 글로벌)
- 수익 구조와 무관하게, **인증 바이어 DB + 문의 데이터**가 핵심 자산
- 투자/펀딩/결제 없음 → 정산·법적 리스크 없음
- 유입은 주로 메타 광고(페이스북 팬페이지 연동) → 이후 틱톡/유튜브/인스타/쓰레드 확장

## 2. 참고 레퍼런스

- 레이아웃/디자인 베이스: **인디고고 신버전** (2025 Gamefound 인수 후 리뉴얼판, https://www.indiegogo.com/en) — 2026-07-27 실사이트 확인 완료
  - 차용: 홈 히어로+실시간 카운터, 카테고리 레일, Spotlight 라이브 피드, 디렉토리 URL 파라미터 필터, 장바구니식 담기 UX
  - 차용 안 함: 펀딩 게이지, 리워드 티어, 백커 댓글/업데이트 탭 (상세페이지는 쇼핑몰 문법으로 단순화)

## 3. 사이트 구조

```
홈           히어로(대표 제품 + 문의 수 카운터) / 카테고리 레일 /
             Spotlight 피드("N시간 전 신제품 등록·문의 접수" 라이브 느낌) /
             칼럼 섹션(필수) / 웨비나 배너 / 하단 "제품 등록하세요"(한국 기업용, 한국어)
디렉토리      카테고리 × 정렬(최신/인기/문의많은순) 필터, 인디고고식 URL 파라미터
제품 상세     아래 4장 참조
칼럼         목록 + 상세. 정적 HTML로 구워서 SEO·AI 검색 노출 (하오디자인 칼럼 시스템 방식)
웨비나        메뉴/카테고리만 개설, "준비 중" 상태. 콘텐츠·신청 기능은 2차 (대표가 자료 별도 제공 예정)
가입/로그인   MST 인증 포함 (5장)
마이페이지    관심제품 목록 / 내 문의 내역 / 프로필(회사 정보)
관리자        제품 등록·칼럼 발행·바이어 명단·문의함·웨비나 관리
```

## 4. 제품 상세페이지 (쇼핑몰 문법, 인디고고보다 단순하게)

```
[상단]  이미지 갤러리  |  상품명 / 브랜드명
                      |  가격 🔒(블러) · MOQ/거래조건 🔒
                      |  [관심제품 담기] [문의하기] [카탈로그 받기 🔒]
[중단]  브랜드 소개 (기업 스토리 짧게)
[하단]  상세 이미지 세로 나열 + 유튜브 영상 삽입, 중간중간 CTA 버튼 반복
[끝]    비슷한 제품 추천
```

## 5. 회원·인증 (확정)

- **비로그인: 전부 열람 가능.** 가격·거래조건·카탈로그만 블러/잠금
- **CTA 클릭 시 가입 모달**: 문의하기 / 관심제품 담기 / 카탈로그 받기 / 가격 보기 / (2차)웨비나 신청
- **가입 = 베트남 세금코드(MST) 인증 필수**:
  1. MST 10자리 입력 → 서버가 조회 API 호출 (api.vietqr.io/v2/business/{MST}, 국세청 데이터. 2026-07-27 동작 확인)
  2. 회사명·주소·활동상태 **자동입력** (수정 불가 — 위조 방지)
  3. 담당자명·직함·**Zalo 번호** 직접 입력 → 가입 완료 = 인증 바이어
- 결과: DB에 100% 실존 베트남 사업자만 쌓임
- VIP 등급: 시스템 개발 없이 운영으로 — 관리자가 Zalo로 직접 컨택해 확인한 바이어를 수동 승격 (한국 기업 직통 연락처 제공, 웨비나 초대)
- Zalo OA/Zalo 로그인(OAuth) 연동은 2차 과제

## 6. 관심제품 (장바구니 방식)

- 헤더에 카트 아이콘 + 담은 수 뱃지
- 제품 카드·상세에 "관심제품 담기" 버튼
- 마이페이지에서 목록 확인, **담은 목록 한꺼번에 문의하기** 가능 (문의 1회 → 제품 수만큼 문의 데이터 생성)

## 7. 언어 (확정: 3개)

- 베트남어(기본) / 한국어 / 영어 — 헤더 토글
- 운영: 관리자에서 **한국어로만 입력 → VN/EN 자동 번역 후 검수** (3벌 수기 작성은 운영 불가)

## 8. 문의 데이터 흐름

```
메타광고 → 제품 페이지 → CTA → MST 가입 → 문의/관심 저장
  → 관리자 문의함 + 실시간 알림 (텔레그램 or 이메일)
  → 바이어 DB (회사명·MST·주소·담당자·직함·Zalo) = 영업 자산
  → Meta Pixel 전환 이벤트 (가입 완료·문의 완료) → 광고 최적화
```

## 9. 기술 스택

- 프론트: 정적 사이트 (인디고고 디자인 미러) — 기존 작업 방식 동일
- 백엔드: **Supabase 무료 티어** — Auth(로그인), DB(바이어/문의/관심), Edge Function(MST 조회 중계 — 클라이언트에서 직접 호출 금지, 서버 중계로 CORS·남용 방지)
- 칼럼: 관리자 작성 → 정적 HTML 굽기 (column-html-bake 방식 재활용)
- 배포: GitHub Pages → 추후 도메인 연결
- 추적: Meta Pixel (가입·문의 전환 이벤트)

## 10. 브랜드

- 이름: **MAKENOV (메이크노브)** 확정
- 로고·컬러: 사이트 제작 시 심플하게 신규 제작 (인디고고식 깔끔한 단색 포인트 컬러)
- 도메인: 미정 (추후 결정, 후보: makenov.com / .co.kr / .vn)

## 11. 운영 로드맵

1. 사이트 오픈 — 대구 기업 제품을 관리자로 직접 등록
2. 페이스북 팬페이지 개설 → 칼럼·제품 콘텐츠 발행 → 팬페이지 연동 메타 광고 (핵심 채널)
3. 틱톡/유튜브/인스타/쓰레드 확장
4. 2차 개발: 웨비나 신청 기능, Zalo 로그인, 바이어 등급 자동화
